Login API — third-party API integration in EDS

The browser posts loginID / password to the local proxy (http://localhost:3030/api/form-submit). The proxy adds the x-secret-header and the Abbott context headers server-side and forwards to https://dev2.services.abbott/api/v2/public/profile/login, then returns the real API response. The secret never reaches the browser — open DevTools → Network and confirm the outgoing request carries no secret.
